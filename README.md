# 🍽️ Restaurant Sales BI Dashboard

Dashboard Business Intelligence interaktif yang dibangun menggunakan **Python**, **Streamlit**, dan **Plotly** untuk memvisualisasikan dan menganalisis data transaksi penjualan restoran secara *real-time*.

## 🚀 Fitur Utama
- **Key Performance Indicators (KPI) Cards**: Memuat Total Omzet, Total Transaksi, Total Qty Terjual, dan Rata-rata *Basket Size*.
- **Tren Penjualan Harian**: Grafik garis interaktif untuk memantau pergerakan omzet dari waktu ke waktu.
- **Analisis Produk & Kategori**: Grafik batang untuk Top Produk terlaris serta diagram donat untuk kontribusi kategori Makanan vs Minuman.
- **Panel Filter Interaktif**: Memfilter data secara dinamis berdasarkan Lokasi Cabang dan Kategori Produk.
